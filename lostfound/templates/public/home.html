How it works

Four steps from “I lost it” to “I've got it back”.

  1. {% icon "file" "icon-lg" %}

    Report an item

    Post what you lost or found with a category, place and time. A photo helps. It takes under a minute.

  2. {% icon "link" "icon-lg" %}

    Find a potential match

    Lost and found reports are compared by description, category, place and time. You're notified of likely matches.

  3. {% icon "clipboard-check" "icon-lg" %}

    Verify ownership

    Answer questions about details the finder kept private. A security officer reviews every claim.

  4. {% icon "key" "icon-lg" %}

    Collect it securely

    Pick it up from the security office with photo ID and a one-time code. Every handover is recorded.

Using the board responsibly

{% icon "package" %} Found something?

Report it, then hand it to the campus security office. Don't arrange handovers directly with people from the board.

{% icon "lock" %} Keep proof to yourself

Never put serial codes, engravings, stickers or bag contents in a public description. They're how the real owner proves it's theirs.

{% icon "hourglass" %} Unclaimed items

Items are held for a set retention period. After that, security reviews them and an administrator authorises disposal or donation.
