{# H. Trust and privacy #}
{% icon "lock" %}Privacy & safety

Your item. Your privacy. A safer return.

Every return follows the same careful process, whoever you are and however many points you have.

{% icon "eye-off" "icon-lg" %}

Private details stay private

Identifying details recorded by finders are encrypted and never shown on the public board.

{% icon "user-check" "icon-lg" %}

Ownership is verified

Claimants answer questions only the owner could know, with limited attempts.

{% icon "shield" "icon-lg" %}

Supervised handovers

The Lost & Found team checks photo ID and a one-time code or signature before release.

{% icon "history" "icon-lg" %}

Accountable custody

Every receipt, transfer and release is recorded in a custody history that can't be edited.

Reporting guidance

{% icon "package" %} Found something?

Report it, then hand it to the campus security office. Please don't arrange handovers directly with people from the board.

{% icon "lock" %} Keep proof to yourself

Leave serial codes, engravings, stickers and contents out of public descriptions. They're how the real owner proves it's theirs.

{% icon "hourglass" %} Unclaimed items

Items are held for a set retention period. After that the team reviews them and an administrator authorises disposal or donation.
