# Lost and Found

A Django web application for managing lost and found items.

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VishalSudhaArul/Lost-and-Found.git
   cd Lost-and-Found
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install django
   ```

4. **Apply migrations:**
   ```bash
   python manage.py migrate
   ```

5. **Run the development server:**
   ```bash
   python manage.py runserver
   ```
